GO! 문구마켓 - 배경 이미지 파일 이름 목록 (게임풍 배경)
================================================

[넣는 방법]
1. 아래 이름 그대로 이미지 파일을 저장하세요. (확장자 .png / .jpg / .webp 모두 가능)
2. 저장 위치: 이미지\배경\  폴더 (이 파일이 있는 폴더)
3. 이미지가 없으면 지금처럼 기본 색·그림이 그대로 나옵니다.
   -> 한 번에 다 안 넣어도 되고, 하나씩 채워도 됩니다.

[중요 - 모든 그림 공통 규칙]
- 글자·간판 텍스트 없이 그려 주세요. (이름표·버튼은 앱이 그립니다)
- 사람(학생·점원) 없이 빈 공간으로 그려 주세요.
- 밝은 파스텔 톤, 귀여운 동화·게임 일러스트풍으로 통일해 주세요.

[AI 생성용 공통 스타일 문구 - 프롬프트 끝에 붙여 쓰세요]
"밝은 파스텔 색감의 귀여운 2D 게임 배경 일러스트, 부드러운 그림자,
 텍스트 없음, 사람 없음, 깨끗하고 단순한 구성, 어린이용 교육 게임 스타일"

   ※ 건물은 그리지 마세요! 건물(층 버튼)은 앱이 그립니다.

4. 1층.png / 5. 2층.png / 6. 3층.png  (각 2000 x 640, 옆으로 긴 그림)

   프롬프트(공통): "문구점 매장 안 풍경, 빈 벽과 바닥, 창문과 조명,
   진열대 없이 빈 공간 (진열대는 앱이 그려요), 옆으로 긴 파노라마"
   층별 색 분위기: 1층 = 하늘색 벽 / 2층 = 크림·주황색 벽 / 3층 = 연보라색 벽
   ※ 그림 아래쪽 1/5은 바닥으로 그려 주세요. (선반이 바닥 위에 서 있는 느낌)

15. 건물.png  (900 x 1100, 세로형)  ← 새로 추가!
   쓰임: 홈 화면과 입장 화면의 3층 문구점 건물 (CSS 건물 대신 그림으로)
   프롬프트: "귀여운 3층 문구점 건물 정면, 지붕 간판 자리는 빈 판으로,
   층마다 창문, 1층에 차양(줄무늬 어닝), 배경은 투명(PNG) 또는 하늘색"
   ※ 중요한 규칙 (앱이 문 애니메이션을 겹쳐 그려요):
      - 건물 아래 "가운데 1/3"은 출입구 자리예요.
        문짝은 그리지 말고, 안쪽이 밝게 보이는 열린 입구로 그려 주세요.
        (앱이 닫힌 문 두 짝을 겹쳐 놓고, 누르면 양옆으로 열려요)
      - 출입구 크기: 그림 너비의 약 30%, 그림 높이의 약 22% (아래 가운데)
      - 글자(간판 글씨)는 넣지 마세요.
