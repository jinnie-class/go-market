GO! 문구마켓 - 효과음 파일 이름 목록
================================================
(2026-07-27 · 효과음은 지금 '앱이 직접 만들어 내는 소리'가 기본이에요)

[이 폴더는 비워 두어도 됩니다]
파일이 하나도 없어도 효과음은 잘 납니다.
앱이 코드로 소리를 만들어 내기 때문이에요. (인터넷에서 받은 효과음은
저작권 문제가 생길 수 있어서, 파일 없이 되도록 만들었습니다.)

[소리를 바꾸고 싶을 때만]
마음에 드는 소리를 구하셨다면 아래 이름으로 이 폴더에 넣으세요.
넣은 것만 바뀌고, 안 넣은 것은 그대로 앱이 만든 소리가 납니다.

  딸랑.mp3   <- 문구점 문을 열고 들어갈 때 (가게 문에 달린 방울)
  띵.mp3     <- 엘리베이터 문이 열릴 때 · 층에 도착했을 때
  삑.mp3     <- 바코드를 찍을 때 (마트 스캐너 소리)
  톡.mp3     <- 바구니에 담을 때
  딩동.mp3   <- 계산이 끝났을 때

확장자는 .mp3 / .wav / .ogg / .m4a 모두 됩니다.

[소리 고르는 기준]
1. 짧게 — 0.5초를 넘지 않게. 길면 다음 행동을 방해해요.
2. 작고 부드럽게 — 청각이 예민한 학생에게 갑작스러운 큰 소리는
   피하고 싶은 자극이 됩니다.
3. 놀라게 하는 소리(경보음·폭발음·큰 박수)는 쓰지 마세요.

[효과음 끄기]
선생님 설정 -> 5번 '음성 안내' 안의 '효과음 끄기'.
음성 안내와 따로 켜고 끌 수 있어요.
조용한 모드(🔕)를 켜면 효과음도 함께 꺼집니다.

[저작권]
효과음도 사진과 마찬가지로 저작권이 있습니다.
'무료 이용 가능'이라고 적힌 것만 쓰시고, 출처를 확인해 주세요.
